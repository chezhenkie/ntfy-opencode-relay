inbound outbound message flow

One self-hosted path from phone to agent and back. The relay is the only process that reads and writes on both sides.

inbound: phone to agent

A message or command typed on the phone becomes a prompt in a running OpenCode session.

outbound: agent to phone

Assistant text and files become a notification. Permission asks carry a short code that a phone reply resolves.

Both directions share one ntfy server and one relay. The phone never reaches the desktop directly; the VPN carries the traffic and the relay is the only reader of the OpenCode event stream.
